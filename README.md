# Surcos Saving

> **Pequeñas monedas. Grandes posibilidades.**  
> Iniciativa educativa y PYME estudiantil vinculada a la comunidad de la **Unidad Educativa Surcos** (Quito, Ecuador) para fomentar el ahorro constante, impulsar el emprendimiento en ferias escolares presenciales y desarrollar habilidades financieras y tecnológicas de alto valor.

---

## 🌟 Características principales

- **Microeconomía del vuelto escolar:** Formación del hábito del ahorro disciplinado a partir de pequeñas cantidades diarias ($0.05, $0.10, $0.25).
- **Simulador financiero pedagógico:** Proyecciones matemáticas interactivas de acumulación, cumplimiento de metas, fechas estimadas de cierre y desglose semanal/mensual.
- **Rutas formativas y retos:** Niveles progresivos de ahorro diseñados para metas escolares tangibles.
- **Simulador de rentabilidad para ferias:** Cálculo de costes variables, fijos, ingresos brutos, margen porcentual y punto de equilibrio para emprendimientos estudiantiles.
- **Sistema de diseño y accesibilidad:**
  - Soporte completo para **Modo Claro**, **Modo Oscuro** y **Modo de Alto Contraste** (WCAG AAA).
  - Microinteracciones, transiciones fluidas y animaciones físicas basadas en la filosofía de Emil Kowalski.
  - Respeto estricto a las preferencias de reducción de movimiento (`prefers-reduced-motion`).
  - Navegación por teclado completa con estados visibles de foco.

## 🚀 Instalación y desarrollo

### Prerrequisitos

- **Node.js** >= 18.18.0 (recomendado v20+ o v22+)
- **npm** >= 9.0.0

### Pasos

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/juxnbernxrdo/surcos-saving-web.git
   cd surcos-saving-web
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la aplicación.

## ⚖️ Aviso pedagógico e institucional

Surcos Saving es un proyecto pedagógico y formativo desarrollado por estudiantes de la **Unidad Educativa Surcos**. **No es una entidad financiera, banco ni cooperativa**, y no realiza captación, custodia ni intermediación de fondos del público. Toda simulación numérica es con fines exclusivamente educativos.
